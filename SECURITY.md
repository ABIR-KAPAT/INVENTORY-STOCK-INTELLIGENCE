# Security Policy

## Supported Versions

We actively support and provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The StockWise team takes security and user data privacy seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email to **[security@stockwise.dev]** with:
   - A detailed description of the vulnerability.
   - Proof-of-concept code, steps to reproduce, or sample payloads.
   - The potential impact and attack vectors.

### What to Expect

- **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 48 hours.
- **Assessment:** We will confirm the issue and determine severity within 5 business days.
- **Fix & Disclosure:** We will work on a patch and coordinate disclosure with you once resolved.

Thank you for helping keep StockWise and our users secure!
